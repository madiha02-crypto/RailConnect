# RailConnect: Railway Reservation and Scheduling Database

## Project Overview
RailConnect is a relational database designed to manage stations, train schedules, coach and seat inventory, passenger bookings, payments, and cancellations without conflicts.

## Repository Structure
* `schema/`: DDL statements to create the database, tables, and constraints.
* `data/`: DML statements to insert the sample data.
* `queries/`: SQL queries for the business questions.
* `diagrams/`: ER diagram and relational schema diagram.
* `docs/`: Project report and detailed documentation.

## Setup Instructions
1. Execute `schema/create_tables.sql` to build the database.
2. Execute `data/insert_data.sql` to populate sample data.
3. Execute `queries/queries.sql` to run the analysis.
